# Event Management System

## Project Brief
Project Brief 06 - Event Management System

## Technology Stack
- MongoDB
- Express.js
- React.js
- Node.js

## Frontend
React.js with Vite

## Backend
Node.js and Express.js

## Main Modules
- User Management
- Event Management
- Participant Management
- Registration Management
- Schedule Management
- Ticket and Attendance Management

## How to Run Frontend

cd client
npm install
npm run dev

## How to Run Backend

cd server
npm install
npm run dev
